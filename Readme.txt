# 🏋️‍♂️ Gimnasio Pau — Sitio Web Corporativo Oficial

Este repositorio contiene el código fuente y los activos del sitio web corporativo de **Gym Pau**, desarrollado como parte del **Reto 9** para el módulo de *Lenguajes de Marcas e Intercambio de Información (LMI)* en 1.º de DAM (IES Henri Matisse, Paterna).

La plataforma funciona como una *Landing Page* de alto impacto visual con arquitectura *One-Page*, diseñada para la presentación empresarial y la captación de clientes de un complejo deportivo de alto rendimiento.

---

## 🚀 Características y Secciones del Sitio

La interfaz ha sido reestructurada sobre una plantilla base de Bootstrap, aplicando una reingeniería completa de estilos CSS nativos para implementar un tema premium oscuro con acentos en rojo (`#ff3e3e`):

* **Estructura Single-Page:** Navegación fluida controlada por el script de la plantilla y clases de Bootstrap, vinculando de forma dinámica las secciones del menú superior (`#hero`, `#about`, `#services`, `#sedes`, `#contact`).
* **Sección Nosotros:** Presentación operacional de la visión de la empresa y la infraestructura tecnológica intermodular.
* **Servicios de Alto Rendimiento:** Exposición de las áreas operativas de Musculación y Peso Libre, Clases Colectivas WOD y el servicio de Asesoría VIP/Nutrición.
* **Sedes Principales:** Bloques adaptados que muestran la Sede Central (Paterna, Valencia) y la Sede Élite (Venice, Los Ángeles).
* **Módulo de FAQ:** Bloque desplegable interactivo con transiciones de Bootstrap Icons para la resolución de dudas frecuentes comerciales.
* **Formulario Team Pau:** Interfaz limpia de contacto con campos validados para la recogida de datos de atletas interesados.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semántico:** Código limpio y optimizado estructuralmente para la jerarquía de nodos.
* **Bootstrap v5.3.3 & CSS3 Personalizado:** Maquetación adaptiva (*Responsive Grid*) mediante el framework, combinada con variables CSS nativas para homogeneizar el color del entorno oscuro.
* **JavaScript (DOM):** Soporte para animaciones AOS (*Animation on Scroll*), comportamiento del menú móvil colapsable y transiciones automáticas.
* **Bootstrap Icons:** Iconografía vectorial utilizada en los bloques informativos de servicios y estado.
